# exec-one-pager

一个面向管理层汇报场景的 Codex Skill。

它将散落的材料整理成一页纸，用表格或流程图讲清楚：

- 发生了什么变化
- 新旧模式差在哪里
- 当前进展到哪里
- 下一步要做什么
- 这件事带来了什么价值

默认交付：

- HTML：方便继续修改
- PNG：适合直接发送或贴入文档
- Markdown：方便复制到飞书等文档工具

## 安装方法

### 方法一：让 Codex 自动安装

把下面这句话发送给 Codex：

> 安装这个技能：https://github.com/Max179436094/exec-one-pager

### 方法二：手动安装

1. 下载或克隆本仓库。
2. 将整个仓库文件夹复制到：

```text
~/.codex/skills/exec-one-pager
```

3. 重新打开 Codex 对话。

安装后可以直接说：

> 使用 $exec-one-pager，把这些材料做成给老板看的一页纸汇报。

也可以使用“一页纸”“总结提炼”“进展汇报”“做成一张表”“把事情讲清楚”等表达触发该技能。

## 文件结构

```text
exec-one-pager/
├── SKILL.md
└── assets/
    └── one-pager-template.html
```

## 使用提醒

- 专有名词、姓名、岗位名和数字必须回到原始材料核对。
- 信息不足时应先补充关键事实，不应自行编造原因。
- 生成 PNG 后需要实际查看排版，确认没有文字溢出、单字掉行或内容被裁切。
